# Portfolio Research

Ứng dụng web phân tích và tối ưu danh mục cổ phiếu Việt Nam.

## Chạy ứng dụng

```bash
pip install -r requirements.txt
streamlit run app.py
```

Người sử dụng nhập API key Vnstock của chính họ trong giao diện.

## Triển khai

Repository này có thể kết nối trực tiếp với Streamlit Community Cloud.

File chạy chính là `app.py`.
